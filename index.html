Хмарні сервіси, які використовуються у проєкті

GitHub — платформа для зберігання коду та контролю версій проєкту.

GitHub Codespaces — хмарне середовище для розробки та редагування коду.

GitHub Pages — сервіс для публікації вебсайтів в Інтернеті.

Про застосунок

Цей вебзастосунок демонструє використання хмарних технологій для розробки та публікації програмного забезпечення.

GitHub зберігає програмний код, GitHub Codespaces надає хмарне середовище розробки, а GitHub Pages дозволяє опублікувати сайт в Інтернеті.

Хмарний сервіс: Microsoft Azure

Microsoft Azure — хмарна платформа, яка надає обчислювальні ресурси, засоби зберігання даних, мережеві можливості та інструменти для розробки й розгортання застосунків.

Моделі послуг: IaaS, PaaS та SaaS — залежно від конкретного сервісу Azure.

Приклади можливостей: Azure Virtual Machines для віртуальних машин, Azure App Service для розміщення вебзастосунків і Azure Blob Storage для зберігання об'єктних даних.
